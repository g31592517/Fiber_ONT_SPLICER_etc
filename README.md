# Fiber_ONT_SPLICER_etc

This repository contains **[Fiber-Network-Management](Fiber-Network-Management/README.md)**, a
standalone FTTH network operations platform. It covers OLTs, ONTs/ONUs, FATs, splitters, fiber
cables and topology, monitoring, alarms, outage correlation and provisioning. It is
independent of the EazPay billing system and designed to be integrated with it later.
